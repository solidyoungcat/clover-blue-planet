## 1. 项目核心定义

### 开发目的
构建一个**异地同步观影** Web + 桌面应用：两位用户在不同设备、不同网络下同步观看同一影片（Bilibili/YouTube/本地视频/直链），同时进行文字聊天、表情、语音消息交互，并共同养育虚拟小宠物。核心理念为「距离不隔爱」。

### 目标用户与场景
- 异地情侣、分隔两地的亲友
- 主力平台：Web 端（浏览器即用）+ Electron 桌面端（完整体验，支持 `<webview>` 嵌入任意网页）
- 桌面端可加载 Bilibili 等限制 iframe 的网站；Web 端受 X-Frame-Options 限制，引导用户下载桌面端

### 技术栈与关键决策

| 层 | 选型 | 版本 | 选型理由 |
|----|------|------|---------|
| 前端框架 | React + TypeScript | 18+ | 生态成熟，组件库丰富 |

## 3. 关键上下文与隐性知识

### 3.1 已解决的关键问题

#### 问题 1：better-sqlite3 在 CI 和 Railway 上编译失败
- **根因**：`better-sqlite3` 是 C++ 原生模块，需要 Python + C++ 编译工具。GitHub Actions Windows Runner 缺 VS 配置，Railway 环境无 Python
- **解决方案**：移除 `better-sqlite3`，替换为纯 JavaScript JSON 文件存储方案（`packages/server/src/db.ts`），消息保存在 `data/messages.json`，每房间保持 1000 条上限，加入房间时推送最近 100 条
- **涉及文件**：`packages/server/src/db.ts`, `packages/server/package.json`, `pnpm-workspace.yaml`

#### 问题 2：GitHub Actions 桌面端构建连续失败（5 次）
- **根因**：`better-sqlite3` 原生编译失败 → 换 `--ignore-scripts` 后 Electron 未安装 → 换 `pnpm rebuild electron` 后 pnpm 路径问题 → Railway 同样问题
- **解决方案**：简化 CI 为仅构建 Web 端。桌面端改为本地构建：`pnpm --filter desktop build`
- **涉及文件**：`.github/workflows/release.yml`

#### 问题 3：GitHub HTTPS 连接不稳定
- **根因**：网络环境限制 GitHub 443 端口，SSH 同样不可用
- **解决方案**：用户从本地终端在 VPN/不同网络下手动推送，偶发性连通

#### 问题 4：密码未加盐哈希
- **根因**：`crypto.createHash("sha256")` 直接哈希，无盐值，同密码同哈希
- **解决方案**：改为 `randomBytes(16)` 每房间独立盐值，`SHA256(salt + password)`
- **涉及文件**：`packages/server/src/rooms.ts`

#### 问题 5：断线不通知对方 + 速率限制内存泄漏
- **根因**：`disconnect` 事件无清理逻辑，`rateLimitMap` 永不释放
- **解决方案**：添加 `socketRoomMap` 追踪，断线时通知对方 `partner-left`，清理 `rateLimitMap` 和 `socketRoomMap`
- **涉及文件**：`packages/server/src/socket.ts`

#### 问题 6：手动触发 CI 无 tag 导致 Release 失败
- **根因**：`workflow_dispatch` 不包含 tag 上下文，`softprops/action-gh-release` 需要 tag
- **解决方案**：本地 `git tag -f v1.0.0 && git push origin v1.0.0 --force` 推送 tag 触发

### 3.2 技术债务与妥协

| 债务项 | 说明 | 原因 | 后续计划 |
|--------|------|------|---------|
| 视频同步用 Socket.IO 中转 | 非 WebRTC P2P，延迟约 100-500ms | MVP 快速上线 | 计划后续改用 WebRTC DataChannel |
| 桌面端无发布安装包 | CI 无法构建，需本地执行 | Electron 打包需要特定编译器 | 本地 `pnpm --filter desktop build` 产出 .exe/.dmg |
| 语音消息为本地 Blob URL | 未上传 CDN，不可跨设备回放 | MVP 简化 | 计划接入 CDN 存储 |
| 消息存储为 JSON 文件 | 非数据库，大规模性能未知 | Railway 无法编译原生模块 | 单房间 < 10000 条足够 |
| 主题系统仅 UI 框架 | `themeStore` 定义了 preset 但未实装切换 UI | 优先级低于核心功能 | 后续迭代 |
| 无认证系统 | 任何人知道 6 位房间码即可加入 | MVP 简化 | 房间密码已加，可进一步加 JWT |
| 无测试用例 | 零单元测试、零 E2E | 开发速度优先 | 需补充覆盖核心路径 |
